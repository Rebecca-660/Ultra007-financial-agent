# 财务分析公式清单

整理日期：2026-10-27，2026-10-28 补充比较和 DCF 后端公式。范围：当前项目实际使用的财务分析、单位转换、校验和 Excel 公式。

历史分析包含 **20 项逐年分析公式和 1 项收入 CAGR**。新增多公司比较及用户确认参数驱动的非金融企业 FCFF DCF，见文末补充。所有正式公式在代码中预先定义，由 Python `Decimal` 执行；AI Agent 调用工具，不自行创造公式或心算财务结果。原有历史 Excel 使用单元格公式复现 Python 结果；新增比较和 DCF 工作簿保存代码计算的数值、参数和公式说明，重算需重新运行代码。

下方历史公式的口径保持不变，新增公式与其适用范围单独列出。

## 二 输入变量说明

IS 表示合并利润表，BS 表示合并资产负债表，CF 表示合并现金流量表。以下金额输入进入分析前，均转换为已验证的原币种基本单位。

| 代码变量 | 中文含义 | 来源 |
|---|---|---|
| `revenue` | 营业收入 | IS |
| `cost_of_sales` | 与营业收入匹配的营业成本 | IS |
| `operating_profit` | 营业利润 | IS |
| `net_income` | 合并净利润，包含非控股股东部分 | IS |
| `parent_net_income` | 归属于母公司股东的净利润 | IS |
| `assets` | 期末总资产 | BS |
| `liabilities` | 期末总负债 | BS |
| `equity` | 期末全部股东权益，包含非控股股东权益 | BS |
| `parent_equity` | 期末归属于母公司股东的权益 | BS |
| `current_assets` | 流动资产 | BS |
| `current_liabilities` | 流动负债 | BS |
| `inventory` | 期末存货 | BS |
| `receivables` | 期末应收账款 | BS |
| `cfo` | 经营活动现金流量净额 | CF |
| `cfi` | 投资活动现金流量净额 | CF，作为输入展示，未单独注册一个分析比率 |
| `cff` | 筹资活动现金流量净额 | CF，作为输入展示，未单独注册一个分析比率 |
| `capex` | 购建固定资产、无形资产及其他长期资产支付现金所对应的已核实项目 | CF |
| `assets_opening` | 期初总资产 | BS |
| `parent_equity_opening` | 期初归母权益 | BS |
| `inventory_opening` | 期初存货 | BS |
| `receivables_opening` | 期初应收账款 | BS |
| `revenue_previous` | 上年营业收入 | 上年 IS 本年主列，或本年 IS 的上年比较列 |

## 三 20 项逐年分析公式

各项共同要求：所需输入已获人工批准，来源和年度匹配，映射唯一，单位已确认，输入币种一致。缺少任何必要输入时，当前项显示 `n.a.` 并记录原因。

“为正”指严格大于零。百分比结果在计算时保存为小数，例如 `0.2`，Excel 再显示为 `20.0%`；代码不额外乘以 100。

### 增长与金额变化

| 编号 | 指标 | 中文公式 | 代码表达式 | 额外条件和显示单位 |
|---|---|---|---|---|
| 1 | 营业收入同比 | 本年营业收入 ÷ 上年营业收入 − 1 | `revenue/revenue_previous-1` | 上年收入为正；百分比 |
| 2 | 合并净利润同比 | 本年合并净利润 ÷ 上年合并净利润 − 1 | `net_income/net_income_previous-1` | 上年合并净利润为正；百分比 |
| 3 | 营业收入变动额 | 本年营业收入 − 上年营业收入 | `revenue-revenue_previous` | 原币种基本单位 |
| 4 | 合并净利润变动额 | 本年合并净利润 − 上年合并净利润 | `net_income-net_income_previous` | 原币种基本单位 |

同比基数为零或负数时，代码不展示普通同比增长率；只要金额输入完整，金额变动额仍可计算。同比的本年值可以为负，不因本年值为负而自动停止。

### 盈利能力

| 编号 | 指标 | 中文公式 | 代码表达式 | 额外条件和口径 |
|---|---|---|---|---|
| 5 | 毛利 | 营业收入 − 营业成本 | `revenue-cost_of_sales` | 金额；采用匹配的营业成本，不用营业总成本代替 |
| 6 | 毛利率 | （营业收入 − 营业成本）÷ 营业收入 | `(revenue-cost_of_sales)/revenue` | 收入为正；百分比 |
| 7 | 营业利润率 | 营业利润 ÷ 营业收入 | `operating_profit/revenue` | 收入为正；百分比；使用年报营业利润口径，可能含投资等收益 |
| 8 | 净利率 | 合并净利润 ÷ 营业收入 | `net_income/revenue` | 收入为正；百分比；不是归母净利润率 |
| 9 | ROA | 合并净利润 ÷ 平均总资产 | `net_income/((assets+assets_opening)/2)` | 期初、期末总资产分别为正；百分比 |
| 10 | ROE | 归母净利润 ÷ 平均归母权益 | `parent_net_income/((parent_equity+parent_equity_opening)/2)` | 期初、期末归母权益分别为正；百分比；不是加权平均 ROE |

### 偿债与流动性

| 编号 | 指标 | 中文公式 | 代码表达式 | 额外条件和口径 |
|---|---|---|---|---|
| 11 | 资产负债率 | 总负债 ÷ 总资产 | `liabilities/assets` | 总资产为正；百分比；总负债包含非付息经营性负债 |
| 12 | 负债权益比 | 总负债 ÷ 全部股东权益 | `liabilities/equity` | 全部权益为正；倍数；不是有息债务与权益比 |
| 13 | 流动比率 | 流动资产 ÷ 流动负债 | `current_assets/current_liabilities` | 流动负债为正；倍数 |
| 14 | 简化速动比率 | （流动资产 − 存货）÷ 流动负债 | `(current_assets-inventory)/current_liabilities` | 流动负债为正；倍数；只剔除存货，可能仍含预付款等项目 |

### 经营效率

| 编号 | 指标 | 中文公式 | 代码表达式 | 额外条件和口径 |
|---|---|---|---|---|
| 15 | 存货周转率 | 营业成本 ÷ 平均存货 | `cost_of_sales/((inventory+inventory_opening)/2)` | 期初、期末存货分别为正；次/年 |
| 16 | 应收账款周转率 | 营业收入 ÷ 平均应收账款 | `revenue/((receivables+receivables_opening)/2)` | 期初、期末应收分别为正；次/年；营业收入作为赊销收入的代理值 |
| 17 | 总资产周转率 | 营业收入 ÷ 平均总资产 | `revenue/((assets+assets_opening)/2)` | 期初、期末总资产分别为正；次/年 |

### 现金流

| 编号 | 指标 | 中文公式 | 代码表达式 | 额外条件和口径 |
|---|---|---|---|---|
| 18 | 经营现金流/净利润 | 经营现金流量净额 ÷ 合并净利润 | `cfo/net_income` | 合并净利润为正；倍数；非正净利润时不作通常现金含量比较 |
| 19 | 经营现金流利润率 | 经营现金流量净额 ÷ 营业收入 | `cfo/revenue` | 营业收入为正；百分比 |
| 20 | 简化自由现金流 | 经营现金流量净额 − 购建长期资产现金支出 | `cfo-capex` | 金额；支出项目及符号已核实；不等同于 FCFF |

## 四 营业收入 CAGR

中文公式：

```text
n = 末年 − 首年
营业收入 CAGR = （末年营业收入 ÷ 首年营业收入）^(1/n) − 1
```

代码中的计算表达式：

```python
(last / first) ** (Decimal(1) / (years[-1] - years[0])) - 1
```

计算要求：至少两个报告年度；年度连续；各年收入均有获准的有效输入；币种相同；首末年收入为正。中间年度是否为正不是当前代码额外检查的条件，但其数值不能缺失。

2022—2025 年对应 `n=3`，不是四个观测年度就使用四次方根。CAGR 是整个区间的一项结果，不是每年各一项。

## 五 平均余额与期间选择

四个辅助公式为：

```text
平均总资产 = （期初总资产 + 期末总资产）÷ 2
平均归母权益 = （期初归母权益 + 期末归母权益）÷ 2
平均存货 = （期初存货 + 期末存货）÷ 2
平均应收账款 = （期初应收账款 + 期末应收账款）÷ 2
```

当前期间选择规则：

- 本年输入取角色为 `current`、数值年度匹配报告年度的主列。
- 期初输入在本年 BS 中寻找对应年度的 `opening` 列，或上年度的 `prior` 列；只有一个符合条件的列才使用。不会在没有可靠期初值时用期末值代替平均值。
- 上年收入和净利润：如果上传了上年度报告，优先选上年原报本年主列；没有该年度报告时，使用本年报表中年度匹配的上年比较列。
- 已上传的上年报告未批准时，不悄悄改用另一个比较数绕过审核。
- `January 1, Y` 保留为 Y 年期初，不直接改写为未经验证的 Y−1 年末。不同报告之间存在重述或期初差异时，保留并要求确认。
- 本次确认采用 `as_reported`，不把后续比较栏静默覆盖为统一重述历史数据；各张原报中的主列和期初列仍保留自身披露口径。

## 六 原始值 修正值和单位换算

先选择获准值：

```text
没有获准修正：有效值 = 原始值
存在获准修正：有效值 = 修正值
修正为 MISSING：有效值 = 缺失，停止依赖它的计算
```

再进行转换：

```text
分析金额 = 有效值 × 单位倍数 × 符号系数
```

单位倍数由原披露确定，例如元为 1、千为 1,000、万为 10,000、百万为 1,000,000、亿元为 100,000,000、十亿为 1,000,000,000。原始主表保持原披露单位；不同币种不自动换汇。

符号系数默认是 1。对 `cost_of_sales`、`capex`，只有解析配置 `outflow_signs` 明确指定 `negative` 时才使用 −1，将已核实的负支出披露转换为正的支出金额；如果转换后仍为负，停止该项输入，不直接取绝对值。其余现金流净额保留正负。

EPS 等项目虽然保留在原表，但没有纳入当前 20 项指标的金额输入；不按整表金额倍数将其当作总额计算。

## 七 基础勾稽公式

### 资产负债关系

```text
差额 = 总资产 − 总负债 − 全部股东权益
```

### 现金余额关系

```text
差额 = 期末现金及现金等价物 − 期初现金及现金等价物 − 现金及现金等价物净增加额
```

每个年度栏分别检查。所需映射唯一且数值齐全时，代码以 `abs(差额) <= 0.05` 判定通过。这里 0.05 是原表披露单位下的容差，没有先统一换算为元。缺少输入记为不可校验，不记为通过；人工修正后关系不成立时会阻止相关批准数据进入计算。

当前没有额外实现“经营 + 投资 + 筹资 + 汇率影响”的现金流四项加总校验，不将未实现的关系列为已通过检查。

### 跨报告比较差异

```text
比较栏标准金额 = 比较栏数值 × 该报表单位倍数
原报标准金额 = 对应年度原报本年主列数值 × 该报表单位倍数
差异 = 比较栏标准金额 − 原报标准金额
```

仅在币种相同、倍数明确、两边数值齐全时比较。当前以精确“不相等”记录差异，没有另设差异金额阈值；不能套用上述 0.05 的勾稽容差。期初列用于对照上一年度原报主列时，单独保留其期初身份和来源。

## 八 Excel 中实际写入的公式逻辑

### 已批准输入链接

```excel
=IF(AND(原始单元格仍匹配获准版本,修正栏仍匹配获准记录),获准来源单元格*单位倍数*符号系数,"需重新审核")
```

上面是便于阅读的逻辑示意；代码会将中文条件替换成实际的 `ISNUMBER`、`ISBLANK`、数值比较和跨 sheet 单元格引用。原值和修正分别保留，零修正不会被当成空白。

### 指标计算与正值前提

```excel
=IF(AND(COUNT(必要输入单元格)=必要输入数量,规定必须为正的输入>0),实际指标公式,"n.a.")
```

每项只检查其所需输入及代码注册的正值条件。所有指标的业务表达式均来自第三节的 `RECIPES`，不会由 AI 临时生成另一套公式。

总分析页从“分析计算”页引用结果；“分析计算”页从已批准源单元格取值。审核和勾稽展示区不作为财务计算的中间输入。

### Excel CAGR

```text
当连续年度收入完整、起止收入为正时：
（最后一年收入单元格 / 第一年收入单元格）^(1 / 首末年度差) − 1
```

代码先判断年度连续和币种一致，再决定是否写入这个公式。百分比显示默认一位小数；金额保留两位小数显示，底层计算不先按显示位数截断。

## 九 图表辅助换算

图表引用计算单元格，缺失值保留空白，不转成零。金额图表根据该图有效值的最大绝对值选择显示倍数：

```text
最大绝对值 >= 1,000,000,000：显示除数 = 1,000,000,000，标注十亿原币种
否则，最大绝对值 >= 1,000,000：显示除数 = 1,000,000，标注百万原币种
否则：显示除数 = 1，标注原币种基本单位

图表金额 = 已计算金额 / 显示除数
```

百分比图表使用除数 1，按百分比格式显示。绝对值只用于选择图表尺度，不把图表上的负金额改为正金额。

## 十 不可计算与尚未启用的项目

以下情况停止相应计算并保留原因：未批准或旧版审核、源文件变化、映射重复或缺失、年度列不唯一、必要数值缺失、币种或单位不明、币种不一致、不符合正值条件、支出符号不符合配置、零分母或其他算术错误。正式工作簿还要求全部主表批准，跨表币种一致。

当前未启用 EBITDA margin、利息保障倍数、有息负债率及 PE/PB/EV 倍数计算，原因分别为组成项或定义未核实、利息口径不足、有息债务组成项不足、缺少市场价格和市值输入。本文件不把它们列为已实现公式。

本次 2022—2025 年正式结果中，80 个逐年项目有 78 个可计算；2022、2023 年“简化自由现金流”因资本支出项目映射不明确显示不可计算，未猜补金额。另有一项整个区间的收入 CAGR。

## 十一 已做的验证与剩余边界

当前版本的 90 项回归测试通过；实际正式工作簿在独立公式引擎中重新计算的 80 个逐年结果，与 Python 结果一致。另独立复算了收入同比、净利率、资产负债率、流动比率、经营现金流利润率和 ROE，共四年 24 项。

这说明当前样本中的计算与公式实现经过检查，不代表任何输入或任何公司都不会出错。数据提取、标准指标映射、年度、单位和财务口径仍需核对。桌面 Microsoft Excel 的原生打开与复算尚未单独执行。

## 十二 多公司比较新增计算

定义位置：`financial_workbook/comparison.py`。用户选择已审核公司，只使用共同报告年度、相同币种与兼容口径。

- 收入指数：当年收入 / 共同基准年收入 × 100；基准收入必须为正，缺失时不计算。
- 样本中位数：对同年度同指标的有效数值排序，奇数取中间值，偶数取中间两值均值；缺失不填零，记录有效样本数。
- 仅同一行业的用户所选样本生成该统计，不称为全行业均值。跨行业仍可比较兼容财务数据，但不生成行业样本统计。
- 比较图表的金额按基本单位 / 100,000,000 显示为亿原币种，百分比不缩放。

## 十三 人工参数驱动 DCF 新增计算

定义位置：`financial_workbook/valuation.py` 的 `FORMULAS` 和计算函数；输入校验在 `research_models.py`。所有比率用小数，金额用原币基本单位。用户须先选择继续，再确认完整参数。

| 项目 | 固定计算规则 |
|---|---|
| 股权成本 Ke | 无风险利率 + Beta × 股权风险溢价 + 额外国家风险溢价 |
| 税后债务成本 | 税前债务成本 × (1 − 债务税盾税率) |
| WACC | Ke × 权益市场价值 / 资本市场价值合计 + 税后债务成本 × 债务市场价值 / 资本市场价值合计；也可使用用户直接确认的 WACC |
| 预测收入 | 上年收入 × (1 + 用户确认的当年增长率) |
| EBIT | 预测收入 × 用户确认的 EBIT 利润率 |
| 经营现金税 | max(EBIT, 0) × 现金税率；不假定负 EBIT 的即期税收抵免或亏损结转 |
| NOPAT | EBIT − 经营现金税 |
| 折旧摊销 | 预测收入 × 折旧摊销占收入比 |
| 资本支出 | 预测收入 × 资本支出占收入比 |
| 期末经营 NWC | 预测收入 × 经营性非现金营运资本占收入比 |
| 经营 NWC 增加额 | 本年期末经营 NWC − 上年期末经营 NWC；首年使用用户核实的基准余额 |
| FCFF | NOPAT + 折旧摊销 − 资本支出 − 经营 NWC 增加额 |
| 终值首年收入 | 最后预测年收入 × (1 + 长期增长率) |
| 终值 NOPAT | 终值首年收入 × 长期 EBIT 利润率 × (1 − 长期现金税率) |
| 终值再投资率 | 长期增长率 / 长期 ROIC |
| 终值 FCFF | 终值 NOPAT × (1 − 终值再投资率) |
| 终值 | 终值 FCFF / (WACC − 长期增长率) |
| 第 t 年折现因子 | 1 / (1 + WACC)^t |
| 经营资产价值 | 各预测年 FCFF 现值之和 + 终值现值 |
| 普通股权益价值 | 经营资产价值 + 超额现金 + 非经营资产 − 有息债务 − 少数股东权益 − 优先股 − 其他请求权 |
| 每股模型价值 | 正的普通股权益价值 / 稀释股数；权益残值非正时不提供每股价格解释 |
| 终值贡献 | 终值现值 / 正的经营资产价值 |
| 相对参考价格差异 | 每股模型价值 / 用户提供的估值日股价 − 1；无参考股价则不计算 |

敏感性分析对用户指定的 WACC 与长期增长率组合重新计算折现、终值和权益价值，长期再投资随增长率一起变化；当 WACC ≤ g 或 g ≥ 终值 ROIC 时保留无效原因。

首版为非金融企业、完整财年末估值、年末折现，不隐含跨期间处理。用户逐年提供情景参数，终值的长期经营口径也由用户确认。既有“经营现金流减资本支出”不直接作为 FCFF。租赁、有息债务、受限现金、非经营资产、少数股东和股数的口径必须在人工依据中核实。

方法依据：[CFA Institute Free Cash Flow Valuation](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)，[Damodaran Excess Returns and Terminal Value](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)。
