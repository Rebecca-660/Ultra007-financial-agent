# Ultra 007 年报分析工作台

2026年10月28日更新。入口仍是项目根目录 `streamlit_app.py`，双击 `启动财报展示.bat` 或按下方命令启动。

本版将 Ultra 007 草图与现有分析后端连接起来：上传年报后由系统核查来源、年度列、币种单位、三表覆盖和可执行的基础勾稽，再生成历史分析。没有逐表人工审核页面，不要求填写审核栏。新结果明确标记为系统校验，不生成虚假的人工批准。

同日追加的版式适配更新：识别全文中的独立主表标题，按期间区分正式年末主表与期初调整表；支持主表从页面下半部开始、标题页与表体分离、无重复表头的连续页面，以及同页的下一张母公司报表边界。金额与项目按照原 PDF 的实际单元格提取，保留空白项目及来源坐标。

估值继续保留两次明确选择：先决定是否继续估值，再填写和确认本次参数。程序不替用户决定增长、利润率、WACC、长期增长率或股数。

## 安装与启动

在项目文件夹打开终端：

```bat
python -m pip install -r requirements.txt -r requirements-ui.txt
python -m streamlit run streamlit_app.py --server.address 127.0.0.1 --server.port 8501
```

本机打开 `http://127.0.0.1:8501`。运行分析继续使用原有 `.env` 与本地嵌入模型配置。只浏览已保存的结果不调用模型。新上传的提取任务调用既有三个 Agent，系统校验、财务计算和估值由代码执行。

文件保存在本机。调用模型时，检索到的相关原文片段会发送给配置的模型服务，不能把原型的纯离线说明直接用于真实模式。

## 明暗主题与语言

右上角的三点菜单提供 **Light、Dark、System**，分别为浅色、深色和跟随系统。两套主题使用相同的橙黄强调色，原生表格、输入框、下拉菜单和图表随主题调整；浏览器记住主题偏好。

侧栏可切换中文、英文和俄语。切换不更改公司、币种或估值参数。原年报字段保留来源原文，标准财务口径和来源信息不会因为翻译而改数。

页面提示、指标与类别、图表标题/图例/单位/工具提示、表格表头、系统校验说明及估值反馈均随语言切换。公司原名保留，已知外文别名显示在旁边；上传清单可选填“公司英文名”和“公司俄文名”。未提供或未核验的外文名称不会自动编造。源报告文件名、原始项目、原列头、披露单位和使用者输入的判断依据保留原文，并在来源区标示。Streamlit 原生菜单与上传控件内部的系统文字由框架提供。

## 上传与自动分析

1. 在“上传年报”拖入或选择文本型 PDF。单份不超过 100 MB，合计不超过 500 MB；不支持无文本扫描件或加密文件。
2. 在清单中填写公司、报告年度、行业、会计准则、财年末和金融／非金融类型。文件名产生的公司和年度只是提示。“列报币种”为可选元数据：原报告没有明确币种时，请填写 CNY、USD 等实际币种；留空时不会默认为人民币。填写后会按原文件哈希、年度和使用者记录保存，既不执行换汇，也不作为逐表财务审核。
3. 多份文件属于同公司时，可以填写上方通用信息并点击“将已填写的通用信息应用到清单”。只应用已填的列；修改上方字段本身不会清空已有逐文件编辑。
4. 点击“按以上公司与年度开始分析”。这是唯一的上传分析触发操作。不会在选择文件、切换页面或修改筛选时自动启动付费任务。
5. 页面显示后台真实进度。任务保存在项目目录，刷新不重复提交。失败时显示原因，可对已确认结束的任务点击重试；未知或仍运行的进程不会被自动重复启动。

系统先在本地预检主表范围、年度列、原页数值、金额单位及可执行勾稽，通过后才建立或复用 RAG 索引。无法识别的金额栏移动、多个仍无法区分的有效主表或跨页单位冲突，会显示具体文件与物理页原因，不会静默丢弃续页，也不会只展示笼统的 RuntimeError。首次大批量年报索引仍可能较慢，提前预检主要避免对已经确定不支持的文件先做耗时索引。

同一公司同一年度请选择一个主报告版本。系统保留跨报告比较差异，并按各年原报本年数分析，不自动统一重述。合法缺失指标保留为空并显示原因；实际来源、单位或勾稽失败会阻止正式分析。

## 财务概览与来源

分析完成后，侧栏选择公司、年度和指标类别。概览显示收入、净利润、收入同比和资产负债率，现金流区域显示经营现金流，以及收入利润、增长、盈利、负债和现金流五类图表。

“财务指标”保留完整已实现的历史指标；“公式与来源”可查看计算定义、输入来源、PDF 物理页和原年报页预览。新任务显示系统校验记录，旧人工审核任务保留其原始历史记录，两者不会混淆。

首页“打开已有年报分析”可直接查看原有正式结果，不重新运行模型。研究项目选择可恢复新上传的项目。随时可以下载与当前运行一致的历史分析 Excel。

## 公司比较

在“公司对比”选择至少两家已完成分析的公司和共同年度，然后点击“生成公司对比”。选择筛选条件本身不启动比较任务。

只比较币种、会计准则和完整财年末兼容的数据，不自动换汇或对齐不同财年。页面展示趋势、比率、收入指数和有效样本数，提供公司对比 Excel。同行业统计仅代表用户选择的样本，不能称为全行业均值。

## 是否继续估值

“财务概览”底部可前往估值，也可选择“本次只看分析”。进入“估值工作台”后需要填写判断人并明确继续或结束。

结束后仍可查看和下载历史结果，估值参数不显示，也不会执行估值。选择继续仅允许进入参数填写，不等于参数已经确认。

金融企业保留历史分析和比较，但当前 FCFF 模型明确提示暂不适用。

## 两种估值方式

**完整经营预测模型**复用现有 FCFF 后端，包含基准经营性营运资本、逐年收入与 EBIT、现金税、折旧摊销、资本支出和营运资本假设、长期利润率与 ROIC、权益价值桥接。支持 Base、Bear、Bull 和直接 WACC 或组成项 WACC。

**简易 FCFF 增长试算**保留草图中的七参数体验：用户提供已核实的基期 FCFF、预测增长率、WACC、长期增长率、预测年数、净债务和股数。它按固定增长率推演现金流，独立标记为简易试算，不能替代完整经营预测。两种模型各自保存草稿、确认和结果。

金额输入明确使用原币基本单位，股数用股；带 `%` 的输入以百分数填写，例如 9.5 表示 9.5%，界面只在提交时转换为后端小数。经验参数初始为空，不自动套用原型的演示值。

首版使用完整财年末估值和年末折现。选择的基准年度、估值日和桥接输入需要对应。完整模型要求 WACC 大于长期增长率，长期 ROIC 大于长期增长率；无效敏感性组合留空并说明原因。

## 参数确认与恢复

填完参数和依据后，勾选“我已核对当前全部估值参数”，再点击计算。输入发生变化时，本次确认自动清除，旧结果不会冒充当前参数结果；历史版本仍然保留并可单独查看下载。

估值输入现明确标注“必填／选填”。简易试算中的全部金额、确认人、预测年数和“整体假设与适用边界”均为必填；完整经营模型中，参考股价为选填，其他当前适用的输入需填写。不存在的桥接金额请明确填 0，留空不等于 0。

已编辑或提交后发现缺项、数值超限、WACC 不大于长期增长率等问题时，对应字段旁显示红字，并列出待修正位置；完整模型会展开有错误的板块。逐年预测表下按年份和列提示缺项。整体依据中的功能测试示例只是输入提示，不会替使用者填写或确认。

仅做功能试用时，可以自行填写“仅用于功能测试，参数为假设值。”等真实说明。合法参数可能计算出非正权益残值；此时仍显示已完成的计算，并解释每股价值为空的原因，不把它作为程序异常。

草稿保存到当前研究任务。返回页面或刷新后可以恢复已填写内容，但不会自动恢复勾选确认。主题与语言切换不会更改数值。

## 摘要与下载

“摘要与导出”提供历史分析 Excel、已生成的公司对比和估值 Excel，以及包含数据版本和参数的 JSON 摘要。可以返回结果或开始新的公司研究。导出不包含 `.env`。


现有三个 Agent、RAG 和历史公式继续复用。网页不另写一套财务计算。旧版人工审核接口为兼容历史运行保留，新网页走自动校验路径。

本版本面向本机单用户使用，尚无多用户账户、扫描件 OCR、自动行业信息采集、换汇、跨财年调整或银行保险专用估值。
